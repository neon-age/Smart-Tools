Supported Unity versions: **6.6, 6.7, 7.0**  
Options available in ***Edit > Preferences > Smart Tools***, key binds can be assigned in ***Edit > Shortcuts***

[Unity Discussions thread](https://discussions.unity.com/t/smart-tools-open-source/1739882)

# Editor:
* Fullscreen Editor toggle for Windows that hides app top bar, except MenuItems ("F11" shortcut)  
  
# Scene View:
* Classic Local/Global shortcut (switch with one key press, ignoring Grid or any other mode)

# Inspector:
* Hide Script field
* ReadOnlyInInspector attribute
* Component selection menu when dragging GameObject into UnityEngine.Object field

# Hierarchy:
* Active toggle inlined with game-object
* Components bar  
* Compact toolbar
* Hide columns header
* Unlock columns min width
* Override items height
* Override horizontal spacing
* Select All Siblings ("A" shortcut)
* GameObject > Selection > Select Same Prefab Siblings (bindable as shortcut)
